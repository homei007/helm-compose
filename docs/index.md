Helm Compose is a community-maintained continuation of the original
[seacrew/helm-compose](https://github.com/seacrew/helm-compose). It is a tool
for managing multiple releases for one or many different Helm charts. It is an
extension of the package manager idea behind Helm and is heavily inspired by
Docker Compose.
